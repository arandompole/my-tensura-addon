My Tensura Addon is a Tensura: Reincarnated addon that adds in new gameplay mechanics and small changes.

I have plans to add in many different things, as of the latest version it adds:
- Naming different bosses and mobs from the Tensura: Reincarnated mod and the Tensura: Not Enough Bosses addon.

---
Version 1.0.0 is only available on curseforge and it requires BOTH Tensura: Reincarnated and Tensura: Not Enough Bosses.

Every other version will only require Tensura: Reincarnated.
